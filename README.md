# LUO’S Portfolio V2

Independent portfolio website: white animated introduction, black masonry gallery, and character design collections.

Website: https://lyf2855931743-max.github.io/luos-portfolio-v2/

Static HTML, CSS, and JavaScript. All media uses relative paths. GitHub Actions publishes on pushes to `main`.

Three equal-width categories in one desktop row: environment, character design, and props. Character design contains girl, guard, bishop, creature, and character scale galleries. Seven displayed collections contain 32 reference images. The keyframe section has been removed from the interface.

This repository is separate from `luos-portfolio`; its workflow only deploys this V2 website.
